Hospital Management System

Project Overview
The Hospital Management System is a Python-based project designed to manage hospital-related information digitally.

Technologies Used
 Python
 SQLite Database
 JSON

Project Files
app.py – Main Python application
config.json– Configuration file
database.db– Database file
setup.py– Setup script
01 PROJECT INFO.txt– Project information
HospitalManagementSystem.postman_collection– Postman collection
  
Installation
1. Download or clone this repository.
2. Extract the project files.
3. Check the project setup instructions.
4. Install the required dependencies.
5. Run the application according to its setup instructions.
   
Purpose
This project demonstrates the use of Python and database management in a hospital management application.
